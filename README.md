# Pulsar Launcher

Pulsar Launcher is a custom Minecraft launcher built with Python, PySide6, and `minecraft-launcher-lib`, specifically designed for Titomfun events.

> Note: I am a solo developer doing my best to follow [Semantic Versioning](https://semver.org/) and [Keep a Changelog](https://keepachangelog.com/). If something is incorrect or missing, feel free to open an issue describing what should be changed!

## Features

- **Microsoft Authentication:** Secure login using official Microsoft accounts.
- **Event Version Management:** Automatic downloading, updating, and launching of custom Minecraft instances for Titomfun events.
- **Modpack Support:** Built-in integration for Forge, Fabric, and NeoForge modpacks.
- **Customizable Settings:** Easily adjust RAM allocation, select custom Java paths, and change game directory locations.
- **Modern UI:** Responsive, clean desktop interface built with PySide6.


## Built With

* [Python 3](https://www.python.org/) - Core programming language
* [PySide6](https://wiki.qt.io/Qt_for_Python) - GUI framework (Qt for Python)
* [minecraft-launcher-lib](https://codeberg.org/JakobDev/minecraft-launcher-lib/) - Library handling Minecraft launcher logic and installations


## Download & Installation

You do not need to compile or run code to use Pulsar Launcher. 

1. Go to the [GitHub Releases](https://github.com/TitomfunDev/pulsar-launcher/releases) page.
2. Download the latest executable for your operating system (Windows / macOS / Linux).
3. Run executable and follow the on-screen instructions.


## Requirements

* An active, official **Minecraft / Microsoft Account**.
* An internet connection for authenticating and downloading required game assets.
